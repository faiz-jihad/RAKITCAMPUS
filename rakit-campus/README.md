# RAKIT Campus — Backend & Web Application

Integrated Laravel 12 + Inertia.js (React 19 + TypeScript + Tailwind CSS) application powering the RAKIT Campus platform.

For full system architecture, documentation, and mobile application guides, see the [Root README](../README.md) and [`docs/`](../docs/).

## Quick Commands

```bash
# Run migrations & seeders
php artisan migrate:fresh --seed

# Build frontend assets
npm run build

# Run PHPUnit test suite
php vendor/phpunit/phpunit/phpunit

# Start local server
php artisan serve
```
